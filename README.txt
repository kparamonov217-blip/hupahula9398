WEBEXCEL LOCAL — личный автономный табличный редактор (Windows 11)

ТРЕБОВАНИЯ
- Windows 11, браузер Edge или Chrome (для окна "Сохранить как" лучше Chromium).
- Node.js LTS (INSTALL.bat попробует поставить через winget).
- Интернет нужен только для установки Node.js. Сам WebExcel работает офлайн:
  все библиотеки лежат в app\vendor.

УСТАНОВКА
1. Распакуйте архив в любую папку (например, C:\WebExcel-Local).
2. Запустите INSTALL.bat.

ЗАПУСК
- START.bat — запускает локальный сервер (127.0.0.1:8765, только ваш компьютер) и открывает браузер.

ОСТАНОВКА
- STOP.bat, либо Файл -> Выход в приложении, либо закрыть свёрнутое окно сервера.

ФОРМАТЫ
- Открытие: .xlsx, .csv, .tsv. Сохранение: .xlsx, .csv (разделитель ";", UTF-8 с BOM).
- Автосохранение: каждые 5 секунд в data\autosave.json и в IndexedDB браузера.
  При следующем запуске книга восстанавливается автоматически.

РЕАЛИЗОВАННЫЕ ФУНКЦИИ
Редактирование, несколько листов, формулы с пересчётом, строка формул и адрес ячейки,
форматирование (шрифт, размер, Ж/К/Ч/зачёркнутый, цвета, выравнивание, перенос, границы,
числовые форматы), объединение ячеек, поиск/замена, сортировка, фильтры, закрепление областей,
диаграммы, условное форматирование, проверка данных (в т.ч. выпадающие списки), сводные таблицы (собственный конструктор: Вставка -> Сводная таблица; строки, столбцы, значения, функции; работает на любых данных, в т.ч. из загруженного XLSX),
вставка строк/столбцов, комментарии, контекстные меню, горячие клавиши (Файл -> Справка).
Основа — движок Luckysheet (MIT), импорт XLSX — LuckyExcel, экспорт — ExcelJS.

ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
- Интерфейс русифицирован частично: лента, статус и основные пункты меню; часть диалогов
  движка (поиск, диаграммы, условное форматирование) остаётся на английском.
- Набор функций Excel — как у Luckysheet (нет динамических массивов, LET, LAMBDA, XLOOKUP и т.п.).
- При импорте/экспорте XLSX возможна потеря: диаграмм, сводных таблиц, условного форматирования,
  проверки данных, макросов (VBA), Power Query, Power Pivot, рисунков и части стилей.
- Экспорт XLSX сохраняет значения, формулы, шрифты, цвета, числовые форматы, выравнивание,
  объединения, ширину/высоту, простые границы.
- VBA, Power Query, Power Pivot, именованные диапазоны — не поддерживаются.
- Приложение собрано автоматически; интерфейс в реальном браузере разработчиком не проверялся
  (см. FEATURES.txt). Если какая-то кнопка не работает — сообщите.

СВОДНЫЕ ТАБЛИЦЫ И ЗАГРУЗКА ФАЙЛОВ
- Сводные таблицы, уже существующие в загружаемом XLSX, приходят как обычные значения
  (движок не импортирует сами объекты сводных таблиц). Чтобы получить живую сводную,
  выделите исходные данные (или встаньте в них) и выберите Вставка -> Сводная таблица.
- Результат сводной — статичная таблица: при изменении исходных данных создайте её заново.

ЗАГРУЗКА XLSX СО СВОДНЫМИ ТАБЛИЦАМИ / МОДЕЛЬЮ ДАННЫХ (Power Pivot)
- При открытии такого файла приложение: показывает все листы и значения сводных таблиц из файла,
  оформляет сводные (шапка, итоги), скрывает листы, скрытые в Excel, и выводит уведомление
  со списком найденных сводных таблиц, срезов и модели данных.
- Сводные, построенные на модели данных Excel, пересчитывать нельзя: исходные таблицы лежат внутри
  бинарной модели (xl\model), которую браузерное приложение прочитать не может. Срезы работают частично (см. ниже).
- При сохранении в XLSX сводные/модель/срезы превращаются в обычные значения. Оригинал не меняется —
  сохраняйте под другим именем.

СРЕЗЫ
- Срезы из XLSX отображаются на листе поверх таблицы в тех же местах и того же размера, что в Excel.
  Клик по значению — выбрать только его; Ctrl+клик — добавить/убрать; ⛒ в заголовке — сбросить;
  заголовок можно перетаскивать. Вид -> Срезы скрывает/показывает все срезы листа.
- Выбор скрывает строки/столбцы сводной, где встречается снятое значение; для сводных с суммами
  итоги пересчитываются, для сводных со средними/счётом итоги остаются как в файле.
- Значения серого цвета — те, которых нет в готовой сводной (их данные лежат только в модели Excel,
  которую приложение прочитать не может): выбрать их нельзя. Состояние срезов сохраняется автоматически.
